## 一、Logo 最終結構

### 核心圖騰

```
開放弧線（單端漸細）＋ 柔和四角星

     ╭──────────╮
    ╱     ★     ╲        ← C 形弧線，起始端細，逐漸變粗，終端微收
   │    (軌跡)   │          開口朝右上 45°
    ╲           ╱           弧線內側為柔和四角星
     ╰──────────╯           星星下方為成長軌跡（選擇性使用）
```

### 三元素角色

| 元素 | 角色 | 必須？ | 說明 |
|:----:|:----:|::----:|------|
| ╭─╮ 開放弧線 | **品牌容器** | ✅ 必須 | 象徵包容與保護，定義 Logo 外輪廓 |
| ★ 柔和四角星 | **品牌核心** | ✅ 必須 | 代表學員的夢想與 AI 魔法 |
| ↗ 成長軌跡 | **品牌敘事** | ❌ 選擇性 | 強化「成長」故事，但非必要辨識元素 |

**核心辨識組合**：開放弧線 ＋ 柔和四角星。即使移除軌跡，仍必須能被辨識為 AI 圓夢魔法學院。

## 二、比例格線

### 基本比例單位

以柔和四角星的內切圓直徑為 **1 單位（U）**。

```
        ╭──────────────╮
       ╱                ╲
      │       ★         │    ← 星星內切圓直徑 = 1U
       ╲                ╱
        ╰──────────────╯

弧線半徑（外緣）：2U
弧線半徑（內緣）：1.6U
弧線開口寬度：1.2U
弧線粗細（最粗處）：0.15U
弧線粗細（最細處）：0.06U（最小線寬）
星星尺寸：1U × 1U
軌跡長度：0.8U（選擇性）
軌跡粗度：0.04U
```

## 三、單端漸細弧線規格

### 路徑描述

```
起始點：弧線左下端（開口底部）
  → 線寬：0.06U（最小線寬）

弧線最粗處：弧線右上 1/3 位置
  → 線寬：0.15U（最大線寬）

終點：弧線右上端（開口頂部）
  → 線寬：0.08U（過渡線寬）

開口方向：右上 45°（2 點鐘方向）

弧線類型：C 形弧，非完全圓弧
  → 使用貝茲曲線（Bézier），使弧線略帶「有機感」
  → 不是數學完美的圓弧，而是微有變化的自然弧線
```

### 最小線寬保證

| 應用場景 | 最小線寬（實際尺寸） | 安全 |
|:-------:|:-------------------:|:----:|
| 數位螢幕（72dpi） | 2px | ✅ 安全 |
| 一般印刷（300dpi） | 0.5pt | ✅ 安全 |
| 燙金/打凹 | 0.5pt | ⚠️ 需確認印刷廠能力 |
| 小尺寸 Logo（48px） | 1.2px | ✅ 可辨識 |
| 極小尺寸（32px） | 不適用弧線 | 改用 Small Icon（僅星星） |

**若印刷或製作時無法保證最小線寬，應改用純色簡化版本或升級為較大尺寸。**

## 四、柔和四角星規格

### 四角星結構

```
四角星 = 四道尖角，間隔 90° 均勻分布

角 A（上）：90° 方向
角 B（右）：0° 方向
角 C（下）：270° 方向
角 D（左）：180° 方向

每個尖角的原始角度：30°
柔化方式：尖角頂端以半徑 12%（相對於星星尺寸）的圓角處理
```

### 標準版 vs 小尺寸版

| 屬性 | 標準版 | 小尺寸專用版 |
|:----:|:------:|:-----------:|
| 適用尺寸 | ≥ 48px | < 48px |
| 圓角半徑（相對） | 12% | 8%（更接近尖角） |
| 線條粗細（如為空心） | 可空心或實心 | 實心（實心在小尺寸辨識度更高） |
| 細節保留 | 完整四尖角 | 四尖角略為加粗 |
| 中心點 | 留白或實心 | 實心 |

### 小尺寸專用四角星規格（New）

```
尺寸區間：32px ∼ 47px
形狀：仍是四角星，不是圓點
變化：
  - 尖角圓角從 12% 降至 8%（更俐落，補償縮小造成的模糊）
  - 整體實心填滿（不保留中心鏤空）
  - 若為單色版本：使用最高對比度配色
  - 若尺寸再小於 32px：使用 Pixel Hinting 版本（見下方）

尺寸 < 32px（如 16×16 favicon）：
  使用 Pixel Hinting 手動調整：
  - 以像素為單位手動繪製四角星
  - 確保在 16×16 網格上至少佔 10×10 像素
  - 尖角以像素階梯代替平滑曲線
  - 最終應仍可辨識為「有四個尖角的形狀」，而非圓形
```

## 八、Logo Family（完整 5 版本）

### 1. Full Logo（完整版）

```
結構：弧線 ＋ 星星 ＋（選擇性軌跡）＋ 中英文全名
排列：橫式（圖示左文字右）
最小寬度：320px
安全留白：四周至少 Logo 高度的 0.5 倍

使用時機：
  - 寬度 ≥ 320px
  - 可清楚顯示中英文名稱
  - 正式文件、網站 Header（桌機）、證書、簡報封面
```

### 2. Horizontal Logo（橫式版）

```
結構：弧線 ＋ 星星 ＋ 中文品牌名（僅中文）
排列：橫式（圖示左文字右）
最小寬度：200px
安全留白：四周至少 Logo 高度的 0.4 倍

使用時機：
  - 寬度 200px ∼ 319px
  - 空間不足以顯示英文時
  - 手機 Navbar、App 內標題
```

### 3. Vertical Logo（直式版）

```
結構：弧線 ＋ 星星 ＋ 中英文品牌名
排列：直式（圖示上文字下）
最小寬度：140px
安全留白：四周至少 Logo 高度的 0.4 倍

使用時機：
  - 直立版面（手機直式、直立廣告牌）
  - 名片背面
  - App 啟動畫面
  - 空間高度足夠但寬度不足時
```

### 4. Icon Only（圖示版）

```
結構：弧線 ＋ 星星
排列：方形（1:1）
最小尺寸：64×64px（高解析螢幕為 96×96px）
安全留白：四周至少 Icon 高度的 0.25 倍

使用時機：
  - App Icon
  - 社群頭像
  - 瀏覽器捷徑
  - Navbar 摺疊狀態
  - Favicon（高解析度）
```

### 5. Small Icon（極簡版）

```
結構：僅柔和四角星（小尺寸專用版）
排列：方形（1:1）
最小尺寸：16×16px（使用 Pixel Hinting 版本）
安全留白：四周至少 Icon 高度的 0.2 倍

使用時機：
  - Favicon（標準 32×32、16×16）
  - 標籤列圖示
  - 頁面角落 tiny mark
  - Loading 動畫
```

## 十、安全留白

### 基本原則

Logo 周圍的留白空間必須至少為 **Logo 高度的 0.5 倍**。

```
範例（Full Logo 高度 = 40px）：
  四周留白 ≥ 20px
  若有其他文字或圖像靠近，留白 ≥ 30px
```

### 各版本安全留白

| 版本 | 最小留白（以 Logo 高度為基準） |
|:----:|:-----------------------------:|
| Full Logo | 0.5x |
| Horizontal Logo | 0.4x |
| Vertical Logo | 0.4x |
| Icon Only | 0.25x |
| Small Icon | 0.2x |

## 十一、錯誤使用方式（Don'ts）

| ❌ 錯誤 | 說明 |
|---------|------|
| 改變弧線開口方向 | 開口必須朝右上 45°，不得朝左、朝下或閉合 |
| 移除星星 | 弧線＋星星是核心辨識組合，不得缺少任何一個 |
| 改變弧線類型 | 不得使用封閉圓環、雙層弧線或 S 形 |
| 變形/拉伸 Logo | 不得改變長寬比、傾斜、旋轉或扭曲 |
| 更換配色 | 不得使用品牌色以外的配色（如紅色、綠色弧線） |
| 添加效果 | 不得添加立體、陰影、光暈、浮雕等效果（除非品牌規範允許） |
| 添加元素 | 不得在 Logo 內或周圍添加其他符號、文字或裝飾 |
| 使用照片背景直接疊加 | Logo 在照片上使用時需使用全白版或全黑版並確保對比度 |
| 與其他 Logo 並排時距離不足 | 兩個 Logo 之間至少保留一個 Logo 高度的空間 |
| 旋轉 Icon Only | App Icon 或社群頭像中的 Icon Only 不得旋轉或傾斜 |

## 十三、印刷與數位使用規範

### 數位使用

| 項目 | 規範 |

## 十五、最終設計理由摘要

### 這個 Logo 如何回答品牌核心問題

> **「這個設計，是否讓第一次接觸 AI 的人感到更安心、更願意開始？」**

| Logo 特性 | 如何讓學員安心 |
|-----------|---------------|
| **開放弧線** | 不是封閉的圓——它歡迎你進來，而不是把你關在裡面 |
| **弧線單端漸細** | 從細到粗，像一條緩緩展開的道路，不急不迫 |
| **柔和四角星** | 尖角但不刺眼——有 AI 的科技感，但不會讓人感到冰冷 |
| **金色點綴** | 金色在直覺上等於「溫暖/有價值」，而不是科技產品的冷光 |
| **不對稱設計** | 不是完美的對稱——完美讓人感到壓力，微微的不對稱讓人感到「這可以接近」 |
| **保留弧線開口方向** | 右上角是人類閱讀的自然終點，讓視線自然地完成一次「從左到右、從下到上的旅程」 |

### 10 年可用性保證

| 面向 | 保證 |
|------|------|
| **不過時** | 幾何基本形狀（弧線＋星星）沒有流行週期 |
| **可演化** | 色彩可隨時代微調，結構不變 |
| **可擴張** | 換色即可用於學院/廣場/市集/講師團等分支 |
| **跨文化** | 弧線和星星是跨文化符號，不需要翻譯 |
| **跨媒介** | 從 16px favicon 到戶外看板都有對應版本 |
