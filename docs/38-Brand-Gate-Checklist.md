## 驗收標準（採用門檻）

- **95 分以上**：✅ 直接採用
- **90–94 分**：🟡 可採用，列入下一版優化清單
- **90 分以下**：❌ 退件重做（Codex 重製，Hermes 複驗）

## 一票否決項（Veto，違反直接退件，不計分）

以下任一項違反，無論其他項多好，直接 ❌ 退件重做：
- 🚫 使用五角星（品牌規範指定四角星 ✦）
- 🚫 小圓或小靈造型與既定設定不一致（小圓＝女巫學徒、小靈＝紫龍精靈）
- 🚫 品牌主色偏離紫／金主色系（出現紅/綠或明顯偏色）
- 🚫 Logo 不符合「魔法之門」核心概念（門/拱門）
- 🚫 畫面風格偏離「溫暖、科技、魔法」世界觀（幼稚化/宗教感/遊戲化過頭）

## Hero 轉換力檢查（首頁適用）

Hero 須在幾秒內傳達四件事（由 HTML 文案層負責，非圖本身）：
1. 我是誰 → AI 圓夢魔法學院
2. 幫誰 → AI 新手、熟齡族、想用 AI 創造第二人生的人
3. 能得到什麼 → 學會 AI、完成作品、建立個人品牌、創造收入
4. 下一步 → 立即加入 / 體驗 / 報名

## 執行原則（CEO 新增）

> 所有設計與修改，都必須提升使用者「理解品牌的速度」，而不是只提升畫面的華麗程度。

## 首頁凍結規則（Homepage Freeze，CEO 新增 MVP 紀律）

當首頁同時符合以下條件，**立即凍結，不再修改**：
- ✅ Build / Lint / TypeScript 全部通過
- ✅ Brand Gate 通過
- ✅ Hero、Navbar、CTA、課程區、Footer 完成
- ✅ 響應式正常（桌機＋手機）
- ✅ 5 秒品牌測試通過

**凍結後禁止因「新靈感」修改首頁**（Hero/Logo/配色等）。僅以下情況可解凍修改：
1. 修 Bug
2. 使用者測試證明有重大問題
3. 影響轉換率的關鍵調整（需 CEO 批准）

**8/3 展示版目標**（非完整網站，而是一條清楚流程）：
1. 首頁（品牌）→ 2. 了解課程 → 3. 點擊 CTA → 4. 完成報名或加入社群。流程順暢即成功。

1. Codex 生成圖片 → 存 `public/images/brand-batchN/`

4. 達標 → 彙整給 CEO 審核
5. 暫不 push、不動程式
