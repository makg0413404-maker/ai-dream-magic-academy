# AI 圓夢魔法學院 · Brand Mood Board

> 本 mood board 用文字與視覺參考描述品牌整體風貌，作為 Logo、App Icon、吉祥物設計前的風格定錨。

---

## 一、整體氛圍關鍵詞

```
溫暖     ・     奇幻     ・     簡潔     ・     可信賴
Warm    ・    Fantasy   ・    Clean    ・    Trustworthy
```

## 二、視覺參考方向（請想像下列畫面）

### 2.1 色彩氛圍

```
主色調：深藍色夜空 + 紫色極光 + 金色星光
參考場景：
  - 宮崎駿《霍爾的移動城堡》的夜空場景——深藍到紫色漸層，星光點點
  - Apple 太空灰色產品的產品照——低調、質感、光影層次
  - OpenAI 官網的深色模式——乾淨的 dark UI，重點用藍色 highlight

不參考的方向：
  - 不要像兒童樂園（彩色繽紛）
  - 不要像科幻電影（冷光、金屬感太重）
  - 不要像傳統補習班（白色日光燈感）
```

### 2.2 材質質感

```
主材質：毛玻璃（Glassmorphism）、柔和光暈、半透明疊層
參考：
  - Apple iOS 的控制中心——毛玻璃背景 + 模糊效果
  - Notion 的卡片設計——乾淨、留白、資訊層級清楚
  - Stripe 官網的深色模式——gradient 光暈點綴在角落

材質感覺：像走進一間掛滿水晶燈的古老圖書館，
         桌面是霧面玻璃，燈光是溫暖的琥珀色。
```

### 2.3 版面與排版

```
參考品牌：
  - Apple（留白、對稱、產品為主角）
  - OpenAI（大字體、清晰層級、深色模式）
  - Notion（卡片式佈局、flexible grid）

特色：
  - 標題大字重（Bold/Black），內文字輕（Regular）
  - 區塊之間有足夠呼吸空間
  - 圓角適中，不過度可愛也不過度尖銳
```

### 2.4 魔法感表現方式

```
不是「哈利波特電影的魔法」——
  而像是「夜晚在池塘邊看到螢火蟲」那種魔法。

更具體說：
  - 不是閃電、爆炸、濃煙
  - 而是微光、漂浮、漸層
  - 像是 Mac 充電線的 LED 燈在暗處亮起的那種感覺
```

## 三、參考品牌／風格範例

| 參考來源 | 參考原因 | 參考元素 |
|---------|---------|----------|
| **Apple.com** | 留白、字體層級、產品展示 | Layout、Navigation、Footer |
| **OpenAI.com** | AI 品牌、深色模式、科技感 | Hero 區塊、色彩策略 |
| **Notion.so** | 卡片設計、資訊架構 | 卡片佈局、圖示風格 |
| **Stripe.com** | 深色模式漸層、光暈 | 背景光暈效果 |
| **Midjourney.com** | AI 創意工具品牌 | 品牌調性、社群感 |
| **A24 電影《媽的多重宇宙》** | 奇幻但不幼稚的視覺風格 | 奇幻元素的成熟呈現 |
| **吉卜力工作室《魔法公主》** | 自然、溫和、有靈魂的奇幻 | 奇幻不靠特效，靠氛圍 |

## 四、吉祥物氣質參考

### 小圓（萌娃）

```
參考人物形象：
  - 《霍爾的移動城堡》的蘇菲——溫柔、堅毅、有智慧
  - 《魔女宅急便》的琪琪——努力學習、有點迷糊但認真
  - 一位戴著老花眼鏡認真研究手機的親切長輩

不是：
  - 像 Line 貼圖那樣的可愛風
  - 像迪士尼公主那樣的精緻
  - 像 VTuber 那樣的二次元風格
```

### 小靈（萌寵）

```
參考動物形象：
  - 一隻發著微光的狐狸或小貓
  - 尾巴尖端像螢火蟲一樣發光
  - 不是真實動物，是「感覺像動物」的魔法光團

感覺像是：
  - 《神隱少女》的塵埃精靈（ススワタリ）——小小的、可愛的
  - 夜晚草叢中的螢火蟲——溫和的光
  - iPhone 充電時的那個小閃電動畫——簡潔、有趣
```

## 五、不該出現的感覺（Anti-Mood Board）

| 避免的感覺 | 原因 | 替代方向 |
|-----------|------|---------|
| ❌ 兒童卡通風 | 目標受眾是熟齡，不是兒童 | 成熟的奇幻感 |
| ❌ 科幻冷光風 | 會讓科技恐懼的受眾更害怕 | 溫暖的光暈 |
| ❌ 傳統補教風 | 沒有品牌差異化 | Apple 風格的簡潔 |
| ❌ 過度裝飾／花俏 | 熟齡友善需要乾淨版面 | 大量留白 |
| ❌ 恐怖谷吉祥物 | 3D 擬真角色容易讓人不舒服 | 扁平／抽象風格 |

## 六、情緒標籤（Emotion Tags）

使用者看到這個品牌時應該感受到的 5 種情緒：

```
① 安心感  — 「這個平台是為我設計的」
② 好奇心  — 「AI 好像沒那麼難」
③ 信賴感  — 「他們懂我的需求」
④ 成就感  — 「我也學會了！」
⑤ 歸屬感  — 「這裡有一群和我一樣的朋友」
```
