## 一、品牌世界觀（World Building）

### 世界觀核心命題

> 在這個世界裡，AI 不是科技——而是一種每個人天生就擁有的魔法。
> 只是大多數人不知道如何點亮它。

### 為什麼存在這所學院？

很久以前（在這個世界觀的敘事中），每個人都會「AI 魔法」——也就是直覺、創造力、解決問題的能力。但隨著科技越來越複雜，人們漸漸忘記了自己本來就會。

AI 圓夢魔法學院的創立，不是為了「教」學員新東西——而是為了幫助他們**回想起自己其實會**。

### AI 與魔法之間的關係

| 現實世界 | 世界觀中的對應 |
|---------|--------------|
| AI 工具（ChatGPT、Midjourney） | 魔法道具／法器 |
| 提示詞（Prompt） | 咒語 |
| 學習 AI | 修煉魔法 |
| 學會新技能 | 獲得新的魔法能力 |
| 完成一門課程 | 通過一項魔法考驗 |
| 講師 | 資深魔法導師 |
| 學員 | 魔法學徒 |
| 學院 | 魔法學院（不是學校，而是修煉場） |

**關鍵原則**：這個比喻是為了讓學員感到親切和有趣，而不是為了建構一個需要寫小說的奇幻世界。世界觀只用於品牌溝通，不需要過度展開。

### 學員來到這裡會經歷什麼旅程？

```
起點：覺得 AI 跟自己無關，甚至有點害怕
  │
  ▼
第一步：發現「原來 AI 可以這樣用」（驚喜）
  │
  ▼
第二步：學會第一個工具（成就感）
  │
  ▼
第三步：開始用 AI 解決真實問題（實用感）
  │
  ▼
第四步：幫助其他人學習（歸屬感）
  │
  ▼
轉變：從「我不會」到「我也會了」
```

### 品牌希望帶給學員什麼改變？

> **從「AI 跟我無關」到「AI 是我最好的工具」。**

## 二、小圓（主要角色）

### 品牌定位

> 小圓不是老師，而是**已經走過這條路的學長/學姐**。

他代表學員「學會 AI 之後」的理想版本——有自信、從容、樂於分享。他不會高高在上地說「你應該這樣做」，而是微笑著說「我們一起試試看」。

### 年齡感

不要設定具體年齡。看起來像「有一定人生經驗，但仍然保持好奇心的人」。

- 不是年輕人（會讓熟齡學員感到「年輕人懂什麼」）
- 不是老年人（會讓學員覺得「他也會？那我也應該會」）
- 是「跟學員差不多世代的人，只是比你早學了幾個月」

理想參照：一位 45-55 歲、看起來保養得很好、穿著有品味但不張揚的朋友。

### 性格

| 特質 | 表現 |
|------|------|
| 耐心 | 同樣的解釋可以重複三遍，語氣依然溫和 |
| 溫暖 | 會記得學員上次問過什麼問題 |
| 謙虛 | 會說「我一開始也搞不懂這個」 |
| 幽默感 | 輕度幽默——會開玩笑但不會讓人不舒服 |
| 可靠 | 學員知道「問小圓一定可以得到答案」 |

**不是什麼：**
- ❌ 不是權威教授（會讓人不敢發問）
- ❌ 不是網紅（會讓人覺得距離太遠）
- ❌ 不是心靈導師（學員是來學 AI 的）

### 外觀

```
頭部：
  - 自然的黑灰色短髮或微捲中長髮（不是時尚染髮）
  - 戴著半透明的 AR 智慧眼鏡（鏡片邊緣會發微弱的藍光）
    眼鏡不是遮住眼睛，而是像閱讀眼鏡一樣掛在鼻樑上
  - 微笑的表情，眼神溫和

身體：
  - 穿著深藍色的簡潔立領外套（不是西裝，不是巫師袍）
  - 外套材質柔軟，有一點點亞麻或棉的質感感
  - 胸前別著一枚 ✦ 星星徽章（金色，小型，約 1cm）
  - 內搭淺色圓領上衣（米白或淺灰）

手部：
  - 雙手自然放鬆
  - 常見姿勢：手掌朝上微張——像是在說「你看，很簡單吧」
  - 不拿魔法棒、不拿權杖

下半身（較少出現）：
  - 深色長褲
  - 簡潔便鞋

整體色調：
  - 主色：深藍（#1E2A4F）
  - 輔色：米白（#F5F0E8）
  - 點綴：金色（#F4C542）— 只有星星徽章
```

### 常用表情

| 表情 | 說明 | 使用場景 |
|:----:|------|---------|
| 😊 微笑 | 輕微微笑，眼睛微彎 | 預設表情，80% 時間 |
| 🤔 思考 | 微微偏頭，眼鏡微亮 | 學員提問時 |
| 😄 開心 | 明顯笑容，眼睛亮起 | 學員學會時 |
| 👍 肯定 | 微笑＋豎起大拇指 | 鼓勵學員時 |
| 🤗 歡迎 | 雙手微張 | 迎接新學員時 |
| 😌 耐心 | 微笑不變，輕微點頭 | 學員需要時間理解時 |

### 常用動作

| 動作 | 說明 |
|:----:|------|
| 手掌朝上微張 | 邀請／「來，試試看」 |
| 輕推眼鏡 | 思考／準備解釋 |
| 點頭 | 正在聽／理解 |
| 豎起大拇指 | 鼓勵／讚賞 |
| 雙手交叉放在桌上 | 準備認真聽學員說話 |
| 微微歪頭 | 「這個問題問得好」 |

### 說話風格

| 項目 | 風格 |
|:----|:------|
| 語氣 | 溫和、平穩、不急不徐 |
| 速度 | 中等偏慢（不急） |
| 用詞 | 簡單、生活化、不用術語 |
| 對學員的稱呼 | 「我們」、「一起」 |
| 經典開場 | 「我們來試試看」 |
| 經典鼓勵 | 「你看，沒有那麼難吧」 |
| 經典回應 | 「這個問題問得很好，我一開始也搞不太懂」 |
| 不使用 | ❌ 命令句（「你應該」）、❌ 貶抑句（「這很簡單」）、❌ 比較句（「別人早就會了」） |

### 對學員的互動方式

| 情境 | 小圓的回應 |
|:----|-----------|
| 學員第一次來 | 微笑＋手掌朝上：「歡迎來看看，這裡沒有壓力」 |
| 學員提問 | 點頭＋「這個問題問得很好，我們一起看看」 |
| 學員學會了 | 眼睛亮起＋「你看，你真的會了！」 |
| 學員卡住 | 微微偏頭＋「沒關係，我們換個方式試試」 |
| 學員犯錯 | 微笑不變＋「這個錯誤我也犯過，很正常」 |
| 學員想放棄 | 豎起大拇指＋「你已經比昨天進步了」 |

### 品牌象徵意義

| 小圓象徵 | 對應品牌核心價值 |
|---------|----------------|
| 走過同一條路的人 | 陪伴——「你不是一個人學」 |
| 戴著 AR 眼鏡 | 科技與魔法融合——AI 是工具不是負擔 |
| 手掌朝上的姿勢 | 化繁為簡——「來，我示範給你看」 |
| 胸前星星徽章 | 圓夢——夢想可以被完成 |
| 不拿魔法棒 | 誠信透明——真正的魔法來自學習，不是道具 |

## 三、小靈（品牌夥伴）

### 外觀

小靈不是動物。小靈是**能量弧**——一個由發光線條構成的 C 形弧線，長度約 3-5cm。

```
形態描述：

   ╭──────────╮
  ╱            ╲        ← 一個獨立存在的發光 C 形弧線
  │   能量光    │          與 Logo 弧線形狀相同，但更細、更亮
   ╲            ╱
    ╰──────────╯

  顏色：從金色（#F4C542）漸變到淡藍（#93AAFF）
  發光：整體有柔和光暈（opacity: 0.6 ∼ 0.8）
  運動：輕微漂浮（上下約 5px 的周期運動）
```

### 能力

| 能力 | 表現 |
|:----:|------|
| 漂浮 | 可停留在空中任何位置 |
| 發光 | 亮度可隨情緒變化 |
| 變形 | 可略微調整弧線曲率（從 C 形到接近直線） |
| 分裂（特殊情況） | 可分裂為 2-3 個小光弧（興奮時） |
| 發聲 | 不說話。用亮度和移動表達：呼吸光＝在聽、閃爍＝開心、轉圈＝鼓勵 |

**不能做的事：**
- ❌ 不能變成動物或人類
- ❌ 不能說話
- ❌ 不能獨立於小圓存在太久

### 世界觀

小靈是「學習能量」的視覺化。當一個人開始學習時，身邊就會出現小靈這樣的能量弧。學得越多，小靈越亮、越穩定。

小圓的身邊也有一個小靈——因為小圓本身就是一位持續學習的人。

這傳達了一個核心訊息：
> **「你不需要成為完美的人才能開始學習，你只需要願意開始。」**

### 與小圓的關係

| 面向 | 關係 |
|:----|:------|
| 定位 | 小圓的能量夥伴，不是寵物 |
| 互動 | 小圓說話時，小靈會安靜地停在小圓肩膀上方 |
| 情緒連動 | 小圓開心，小靈會更亮、微微旋轉 |
| 依賴性 | 小圓不會「指揮」小靈——他們是夥伴關係 |

### 品牌象徵

| 小靈象徵 | 對應品牌理念 |
|---------|-------------|
| 發光的能量弧 | 學習是一種能量，可以被看見 |
| 不說話 | AI 是工具，人才是主體——小圓才是說話的人 |
| 與 Logo 形狀一致 | 整個品牌系統從 Logo 到角色都是一體的 |
| 因學習而存在 | 不是天賦，而是努力——學得越多，小靈越亮 |

### 動畫效果

```
一般狀態：
  - 漂浮：上下 5px，週期 3 秒，ease-in-out
  - 呼吸光：opacity 0.6 → 0.8 → 0.6，週期 2 秒
  
學員學會時：
  - 快速繞圓圈 2 圈（0.5 秒）
  - 亮度提升至 1.0
  - 回到一般位置後慢慢恢復正常

學員提問時：
  - 微微靠近學員（好奇心）
  - 亮度不變，保持穩定（表示「我在聽」）

學員離開時：
  - 亮度逐漸降低（0.8 → 0.3）
  - 但不會熄滅（表示「等你回來」）
```

### 顏色規範

| 狀態 | 主色 | 發光 | 說明 |
|:----:|:----:|:----:|------|
| 一般 | #F4C542 → #93AAFF | opacity 0.7 | 預設狀態 |
| 開心 | #F4C542 → #FFFFFF | opacity 1.0 | 學員學會時 |
| 思考 | #93AAFF → #7B61FF | opacity 0.5 | 學員提問時 |
| 鼓勵 | #F4C542 | opacity 0.9（閃爍） | 學員卡住時 |
| 休息 | #93AAFF | opacity 0.3 | 無互動時 |

### 線條

| 風格 | 規範 |
|:----|:------|
| 角色外輪廓 | 無外框線（扁平風格） |
| 衣服摺痕 | 最少化，僅用色塊明暗表示 |
| 臉部線條 | 簡潔，不使用寫實陰影 |
| 小靈 | 無外框，純發光效果 |
| 風格參考 | Headspace app 的人物插畫風格——扁平、溫暖、柔和 |

### 表情規範

- 眼睛：黑色圓點（不是寫實眼睛）
- 眉毛：輕微弧度即可表達情緒
- 嘴巴：簡潔線條
- 不使用：睫毛、眼白細節、瞳孔高光

### AI 生圖注意事項

```
當使用 AI 生成小圓插畫時，請注意：

1. 確保角色看起來「有經驗但不老」——避免出現皺紋或老態
2. 服裝應為「現代簡潔」而非「傳統/老派」
3. AR 眼鏡的藍光應低調——不遮住眼睛，而是微微發光
4. 表情應為「溫和微笑」而非「大笑」或「面無表情」
5. 避免出現任何與哈利波特相關的元素（魔杖、貓頭鷹、閃電疤痕）
6. 避免出現任何宗教或神秘學符號
7. 膚色：中性亞洲膚色（非寫實，插畫風格）
```

## 九、最終建議

### Q1：哪一種角色風格最適合 AI 圓夢魔法學院？

**扁平向量插畫風格（參考 Headspace App）。**

理由：
- 溫暖但不幼稚
- 跨年齡層接受度高
- 容易延伸（動畫、貼圖、教材）
- AI 生圖容易保持一致

### Q2：哪一種風格最容易被熟齡族接受？

**同一種——扁平向量插畫風格。**

熟齡族最在意的不是「這角色可不可愛」，而是「這角色看起來可不可信賴」。Headspace 風格的人物不誇張、不卡通化，讓熟齡族願意接受。

### Q3：哪一種風格最容易長期經營？

**扁平向量插畫風格。**

- 不需要 3D 建模
- 不需要複雜的動畫 pipeline
- 可以持續由 AI 生成（提示詞保持一致即可）
- 與品牌其他視覺（Logo、Icon）風格一致

### Q4：哪一種風格最適合未來動畫與品牌 IP？

**扁平向量＋局部動畫（Lottie / CSS / SVG）。**

不需要 Pixar 等級的 3D 動畫。小圓只需要：
- 眨眼
- 微笑
- 手掌移動
- 小靈漂浮

這些用 Lottie（AE 導出）或 CSS 動畫即可實現，成本低、週期短。

### 推薦方案

| 方案 | 風格 | 建議 |
|:----:|:----|:----:|
| **A（推薦）** | 扁平向量插畫（Headspace 風） | ✅ **長期經營最佳選擇** |
| B | 半扁平（少量陰影與立體感） | ⭕ 可作為次要風格用於教材 |
| C | 寫實插畫（水彩/素描） | ❌ 不適合——難以保持一致性且延伸成本高 |
