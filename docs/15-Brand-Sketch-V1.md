## 一、品牌系統擴張原則

### 核心架構

```
AI 圓夢魔法 │ 學院 / 廣場 / 市集 / 講師團
─────────────────
品牌核心（圓夢魔法世界）
  ├── 共同視覺語言（光環 + 星星 + 軌跡）
  ├── 共同色彩系統
  └── 共同世界觀
       ├── AI 圓夢魔法學院 → 教學場域
       ├── AI 圓夢魔法廣場 → 社群交流場域
       ├── AI 圓夢魔法市集 → 作品/服務交易場域
       └── AI 圓夢魔法講師團 → 師資品牌
```

### Logo 共用策略

所有分支使用**同一組核心圖騰**（開放光環 + 星星），只改變：
- 輔助色彩（學院藍、廣場金、市集暖橘、講師團紫）
- 文字標示
- 光環開口角度微微調整

這樣使用者看到任何一個分支都能立刻認出「這是圓夢魔法的東西」。

## 二、Logo 草圖（5 個方向）

### 草圖 1：經典開放弧（推薦優先測試）

```
結構描述（SVG 概念）：
  
       ╭────────╮
      ╱  ★      ╲       ← C 形弧線（開口朝右上 45°）
     │           │        弧線粗細 3px，兩端漸細
      ╲         ╱        弧線顏色：魔法藍 #4F7CFF
       ╰────────╯        星星顏色：魔法金 #F4C542
                          星星置於弧線內側偏右上

文字置於圖示右方：
AI 圓夢魔法學院
AI Dream Magic Academy（小字）

可擴張測試：將「學院」改為「廣場」→ 弧線顏色改金色 → 其餘不變 → 仍可辨識為同一品牌
```

**辨識度**：⭐⭐⭐⭐⭐（弧線＋星星＝獨特組合，市面上無雷同）
**延展性**：⭐⭐⭐⭐（可水平/垂直排列，可單獨使用弧線或星星）
**小尺寸**：⭐⭐⭐⭐（48x48 時弧線和星星仍可辨識）

### 草圖 2：雙層光環

```
結構描述：

       outer ring（外弧，75% 透明）
     ╭────────────╮
    ╱  ╭────────╮  ╲
   │  │   ★    │   │    ← 內弧實心，外弧半透明
    ╲  ╰────────╯  ╱     雙弧線開口方向一致
     ╰────────────╯      象徵「陪伴（外）」與「成長（內）」

文字置於下方
```

**辨識度**：⭐⭐⭐⭐（雙層有層次感，但小尺寸時外弧可能不明顯）
**延展性**：⭐⭐⭐⭐⭐（雙層結構可衍生為「進度系統」— 內弧填滿代表學習進度）
**小尺寸**：⭐⭐⭐（48x48 時雙層可能太擠）

### 草圖 4：環中星（閉合光環）

```
結構描述：

     ╭─────────╮
    ╱           ╲
   │      ★     │        ← 封閉的圓環（不是開口弧）
    ╲           ╱         星星在圓環正中央
```

**小尺寸**：⭐⭐⭐⭐⭐（圓形＋中心星點，最小尺寸仍然清晰）
**風險**：缺乏獨特性

### 草圖 5：星軌交織

```
結構描述：

     ╭──╮
    ╱ ★  ╲
   │      │        ← 弧線與星星的軌跡交織
```

**延展性**：⭐⭐⭐（不對稱設計，應用時需較多調整）
**小尺寸**：⭐⭐⭐（兩個星星在小尺寸可能模糊）

## 三、Logo 草圖選擇建議

| 草圖 | 建議 | 理由 |
|:----:|:----:|------|
| **1** | ✅ **建議優先發展** | 最平衡：獨特＋簡單＋可擴張 |
| 2 | ⭕ 保留為備用 | 雙層概念可作為進度 UI，不一定要當主 Logo |
| 3 | ⭕ 保留為次方案 | 如果確認想要更強的「成長感」 |
| 4 | ❌ 不建議 | 封閉圓環＋星星不夠獨特 |
| 5 | ⭕ 可考慮 | 如果確認想要更動態、更複雜的視覺 |

**我的建議：先以草圖 1（經典開放弧）為核心發展，草圖 3（軌跡弧線）保留為次方案。**

## 四、App Icon 草圖（3 個）

### Icon A：弧星版（對應 Logo 草圖 1）

```
外形：iOS 圓角方形
背景：深藍到深紫漸層（徑向，中心微亮）
主體：金色 C 形弧線（開口朝右上 45°）
內部：白色 ✦ 星星
弧線粗度：4px（確保小尺寸可見）
星星大小：佔 Icon 高度的 40%

測試 48x48：弧線和星星都清晰
測試 24x24：星星縮小為光點，弧線仍可見 → 仍可辨識
```

### Icon B：純星版（極簡方案）

```
外形：iOS 圓角方形
背景：深藍色
主體：白色 ✦ 星星（無弧線），星星略大（佔 Icon 高度 60%）
光效：星星周圍有微弱金色光暈

優點：極簡、Apple 風格
缺點：單獨星星辨識度較低（市面上太多星星 App Icon）
適用：當品牌夠成熟時，可簡化至此版本
```

### Icon C：星軌版（對應 Logo 草圖 3/5）

```
外形：iOS 圓角方形
背景：深紫到深藍漸層
主體：白色星星 + 一條從左下到右上的發光弧線（穿過星星）
動態感：弧線在星星「背後」，像是星星劃過的軌跡

48x48 測試：弧線和星星的相對位置仍可辨識
```

**Icon 建議：以 Icon A（弧星版）為主要方向，因為它與 Logo 草圖 1 共用相同視覺語言。**

## 五、吉祥物草圖

### 小圓（AI 魔法導師 Mentor）

**角色設定調整（根據你的回饋）：**

| 項目 | 內容 |
|------|------|
| 定位 | AI 魔法導師（Mentor）— 陪伴、引導、鼓勵 |
| 與學員的關係 | 不是「教」學員，而是「陪」學員。他會說「我們一起試試看」而非「你應該這樣做」 |
| 外觀方向 1：學院風 | 穿著深藍色的簡潔制服（像天文館解說員），胸前有 ✦ 徽章，戴著半透明的 AR 眼鏡（鏡片會發微光） |
| 外觀方向 2：日常風 | 穿著淺色亞麻襯衫或開襟外套，簡單、溫暖、沒有制服感，更像一位值得信賴的朋友 |
| 手部姿勢 | 手掌朝上，像是在說「來，我們一起看看」——不是指著東西教訓，而是邀請 |
| 道具 | 不拿魔法棒。可以拿著一台平板或手機（上面顯示著 ✦ 星星） |
| 面部表情 | 微笑、眼神溫和、看起來像是聽你說完話後會點點頭說「嗯，我懂」的那種人 |
| 年齡 | 不設定具體年齡。看起來像「有一定人生經驗，但仍然保持好奇心的人」 |

**建議：外觀方向 1（學院風）＋ 方向 2 的溫暖氣質 = 正式但有溫度。**

**草圖方向（概念）：**

```
[ 全身概念 ]
  頭部：自然黑髮/灰黑髮，微捲，戴半透明 AR 眼鏡
  身體：深藍色立領外套（簡潔、沒有多餘裝飾）
  胸前：✦ 星星徽章（金色，小型）
  雙手：自然微張，手掌朝上，高度在腰部
  腳下：站著的地方有一個微弱的光環（不是踩著，而是光環在地面與他之間）

[ 半身概念（未來常用版本）]
  頭部＋肩膀＋手掌朝上的手勢
  背景：淡藍色到紫色的柔和漸層
```

### 小靈（AI 魔法夥伴）

**角色設定：**

| 項目 | 內容 |
|------|------|
| 定位 | AI 魔法夥伴 — 非動物，是能量型存在 |
| 形態 1：能量弧 | 一個小型的發光 C 形弧線（呼應 Logo 的開放光環），長度約 3-5cm，可以在空中漂移 |
| 形態 2：星團 | 由 5-7 個微小光點構成的動態星座，光點之間有發光線條連接 |
| 顏色 | 主體：暖金色到白色漸層，移動時尾巴帶有淡藍色螢光 |
| 行為 | 安靜時：以 C 形弧線靜止在學員視線邊緣 興奮時：快速繞小圓旋轉或畫出軌跡 |
| 與小圓的關係 | 小靈是小圓的能量夥伴，沒有小靈，小圓的魔法（教學能力）就無法運作。象徵「AI 是人的夥伴，不是取代人的工具」 |
| 聲音 | 不說話。用光亮的變化和移動方式來表達： 緩慢呼吸光 = 在聽 快速閃爍 = 同意/開心 轉圈 = 鼓勵 |

**建議：形態 1（能量弧）與 Logo 視覺語言一致，且更容易在小尺寸辨識。**
