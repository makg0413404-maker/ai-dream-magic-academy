## 一、美容行業

### 行業簡介

美容行業涵蓋美髮沙龍、美甲工作室、護膚保養、SPA 按摩等。這類業者需要透過視覺內容展示「變美」的過程與成果，客群以女性為主（25–60 歲），重視專業感、放鬆感與信賴感。

✦ **AI 工具建議**：圖片用即夢／ChatGPT、影片用豆包分身、文案用 ChatGPT

---

### 1.1 美容 × 圖片咒語（適合即夢、ChatGPT）

**✦ 咒語模板**

```
【角色】
你是一位專業美容攝影與 AI 繪圖師，擅長拍攝護膚保養與美髮美甲的形象照。

【任務】
為 {{美容類型}} 業者生成一張專業形象圖片，用於 {{用途}}。

【風格】
- 畫面風格：{{風格}}（溫暖自然 / 高級質感 / 清新明亮）
- 色調：{{色調}}（暖金色調 / 冷白高級感 / 粉嫩甜美）
- 燈光：柔和自然光，凸顯膚質與產品質感
- 構圖：{{構圖}}（特寫產品 / 人物使用過程 / 場景氛圍）

【細節】
- 主要視覺元素：{{主要元素}}（如保養品瓶罐、美容工具、舒適毛巾等）
- 背景環境：專業美容室，簡潔溫暖，木質或白色調
- 人物（若有）：手掌或側臉入鏡，傳遞溫柔專業感

【輸出格式】
- 比例：{{比例}}（1:1 社群貼文 / 4:5 限動 / 16:9 廣告）
- 文字疊加需求：{{文字}}（不需文字 / 加上品牌名 / 加上服務項目）
```

**✦ 預期產出範例**

> **輸入**：美容類型 = 臉部護膚、用途 = 社群貼文、風格 = 溫暖自然、色調 = 暖金色調、構圖 = 人物使用過程、主要元素 = 精華液與化妝棉、比例 = 1:1、文字 = 加上「寵愛自己，從臉開始」
>
> **輸出咒語**（完整版）：
>
> 你是一位專業美容攝影與 AI 繪圖師，擅長拍攝護膚保養的形象照。
>
> 為臉部護膚業者生成一張專業形象圖片，用於社群貼文。
>
> 畫面風格溫暖自然，暖金色調，柔和自然光凸顯膚質光澤。構圖為人物使用過程——一位女性的手正在以化妝棉輕拍精華液，動作溫柔優雅。背景為簡潔木質調美容室，光線從窗邊灑落。主要視覺元素為精華液瓶罐與化妝棉，畫面乾淨有質感。
>
> 比例 1:1，上方加上「寵愛自己，從臉開始」，字體使用優雅的手寫風格，金色字樣。

**✦ 注意事項**

- 避免過度修圖感（熟齡客群重視真實）
- 產品與服務要清楚可見，不要讓 AI 自由發揮模糊的物品
- 文字疊加建議使用品牌色金色 #F4C542 或深色底

### 1.2 美容 × 影片咒語（適合豆包分身、ChatGPT）

**✦ 咒語模板**

```
【角色】
你是一位專業美容影片腳本作家，專為美容沙龍與護膚品牌撰寫 30–60 秒短影片腳本。

【任務】
為 {{美容類型}} 業者撰寫一支短影片腳本，主題為 {{主題}}（服務介紹 / 前後對比 / 教學分享 / 顧客見證）。

【影片結構】
┌─── 開場（0–5 秒）：{{開場方式}} ─── 抓住注意力
│   （範例：問題提問、驚人前後對比、溫馨標語）
├─── 主體（5–45 秒）：{{主體內容}} ─── 展示過程
│   1. {{步驟一}}
│   2. {{步驟二}}
│   3. {{步驟三}}
├─── 結尾（45–60 秒）：{{結尾}} ─── 引導行動
│   （預約資訊、優惠活動、品牌理念）

【角色／旁白】
- 旁白語氣：{{語氣}}（溫暖專業 / 活潑親切 / 知性優雅）
- 旁白人設：{{人設}}（美容師本人 / 專業旁白 / 顧客視角）

【視覺風格】
- 色調：柔和溫暖，低飽和
- 場景：美容室實景或乾淨棚拍
- 字幕：{{字幕需求}}（全程字幕 / 重點字幕 / 不需字幕）

【輸出格式】
- 影片長度：{{長度}} 秒
- 比例：{{比例}}（9:16 直式 / 16:9 橫式）
- 背景音樂：{{音樂風格}}（輕柔鋼琴 / 療癒水聲 / 輕快節奏）
```

**✦ 預期產出範例**

> **輸入**：美容類型 = SPA 按摩、主題 = 服務介紹、開場方式 = 溫馨標語「你有多久沒有好好放鬆了？」、主體內容 = 從進門到結束的完整流程、步驟一 = 迎賓花茶與諮詢、步驟二 = 全身精油按摩、步驟三 = 熱石放鬆、結尾 = 顯示預約資訊與限時優惠、語氣 = 溫暖專業、人設 = 美容師本人、字幕需求 = 全程字幕、長度 = 60 秒、比例 = 9:16、音樂風格 = 療癒水聲
>
> **輸出腳本**（簡要）：
>
> 開場 0-5 秒：畫面從 SPA 門口的溫暖燈光開始，旁白：「你有多久沒有好好放鬆了？」字幕同步顯示。
>
> 主體 5-45 秒：① 迎賓區（5-15 秒）：一杯花草茶的畫面，旁白：「從一杯溫暖的花茶開始，讓我們認識你的需求。」② 按摩區（15-30 秒）：美容師進行全身精油按摩，旁白：「精選天然精油，搭配專業手法，讓每一寸肌肉都得到照顧。」③ 熱石區（30-45 秒）：熱石放在背部的特寫，旁白：「最後用熱石釋放深層壓力，暖意從身體延伸到心裡。」
>
> 結尾 45-60 秒：黑色底畫面，金色文字：「首次體驗 8 折優惠」，旁白：「預約你的放鬆時光，我們在 OOO 等你。」

**✦ 注意事項**

- 影片長度控制在 60 秒內（社群平台最佳長度）
- 熟齡客群偏愛「看到真實的人」——建議讓美容師本人入鏡
- 前後對比內容需有明確進步感，但要真實不誇大
- 預約資訊要清楚、字要大

### 1.3 美容 × 文案咒語（適合 ChatGPT、Gemini）

**✦ 咒語模板**

```
【角色】
你是一位經驗豐富的美容行銷文案寫手，擅長打動女性客群。

【任務】
為 {{美容類型}} 業者撰寫一篇 {{用途}} 文案（Facebook 或 Instagram 貼文），目標讀者是 {{目標客群}}。

【文案結構】
┌─── 標題（1 行，<15 字）：{{標題}}
│   吸引目光，傳遞核心價值
├─── 開場（1-2 句）：{{開場}}
│   引起共鳴的問題或情境
├─── 主體（3-5 句）：{{主體}}
│   為什麼選擇我們 → 服務特色 → 顧客感受
├─── 見證（1-2 句，選擇性）：{{見證}}
│   真實顧客心得或數據
├───CTA（1 句）：{{CTA}}
│   引導行動：預約、來電、私訊

【語氣】
- 語氣：{{語氣}}（溫暖療癒 / 專業自信 / 親切日常）
- 長度：{{長度}}（短版 100-150 字 / 標準 200-300 字 / 長版 300-500 字）
- 表情符號：{{表情}}（適度使用 / 少量使用 / 不使用）

【注意】
- 不使用誇大用語（「奇蹟」、「瞬間變白」等）
- 主詞用「你」和「我們」，不是「我們的產品」
- 熟齡客群用詞：保養、照顧、放鬆、寵愛自己
```

**✦ 預期產出範例**

> **輸入**：美容類型 = 美甲工作室、用途 = 新客引流、目標客群 = 35–55 歲女性上班族、標題 = 你的指尖也需要放假、開場 = 「每天敲鍵盤的手，值得一點美麗的獎勵。」、主體 = 我們懂你想要的——持久又優雅的美甲款式 → 日式凝膠美甲，3 週不掉色 → 顧客說「做完心情都好了」、見證 =「第一次做美甲，比想像中還美！」、CTA = 私訊預約享新客 9 折、語氣 = 溫暖療癒、長度 = 標準、表情 = 適度使用
>
> **輸出文案**：
>
> ✦ 你的指尖也需要放假 ✦
>
> 每天敲鍵盤的手，值得一點美麗的獎勵 💅
>
> 我們懂你想要的——持久、優雅、不麻煩。
> 日式凝膠美甲，精選 200+ 色系，
> 一次維持 3 週不掉色，
> 洗完頭、做完家事依然完美如初。
>
> 「第一次做美甲，比想像中還美！」
> ——這是我們最常聽到的回饋 💕
>
> 這個月，私訊預約享新客 9 折優惠。
> 來讓你的指尖，也放個假吧。
>
> ✦ OOO 美甲工作室

**✦ 注意事項**

- 美甲/美容的文案要避免「痛點攻擊」（「你還在用粗糙的手見人嗎？」）
- 善用「寵愛自己」、「對自己好一點」等溫暖角度
- CTA 要具體（私訊預約 / 來電 / LINE 加入）
- 避免承諾醫療效果（美白、抗老等需醫療字號）

## 二、餐飲探店行業

### 行業簡介

餐飲探店涵蓋餐廳、小吃、咖啡廳、烘焙坊、美食推薦等。內容以「視覺食慾」為核心——讓看的人感受到好吃、想去吃。目標客群廣泛，從家庭客到年輕族群都需要。重點在氛圍營造、食物特寫與真實體驗感。

✦ **AI 工具建議**：圖片用即夢（食物攝影最強）、影片用豆包分身、文案用 ChatGPT

---

### 2.1 餐飲探店 × 圖片咒語（適合即夢、ChatGPT）

**✦ 咒語模板**

```
【角色】
你是一位專業美食攝影師與 AI 繪圖師，擅長拍攝讓人食指大動的食物與餐廳氛圍照。

【任務】
為 {{餐飲類型}} 生成一張專業美食／餐廳形象圖片，用於 {{用途}}。

【風格】
- 畫面風格：{{風格}}（溫暖生活感 / 高級質感 / 文青簡約 / 復古懷舊）
- 色調：{{色調}}（暖橘食慾色 / 冷調高級感 / 自然日光感）
- 燈光：{{燈光}}（側光強調紋理 / 頂光均勻明亮 / 窗邊自然光）
- 景深：淺景深（食物主題清晰，背景模糊）

【細節】
- 主要食物：{{主要餐點}}（請具體描述）
- 擺盤風格：{{擺盤}}（精緻分子料理 / 家常溫暖擺盤 / 大份量豪邁）
- 背景元素：{{背景}}（木桌＋餐具＋餐巾／大理石桌面／餐廳內景／窗邊）
- 額外道具：{{道具}}（菜單、鮮花、酒杯、咖啡杯等）

【輸出格式】
- 比例：{{比例}}（1:1 社群 / 4:5 限動 / 16:9 廣告）
- 文字疊加：{{文字需求}}
```

**✦ 預期產出範例**

> **輸入**：餐飲類型 = 早午餐咖啡廳、用途 = Instagram 貼文、風格 = 溫暖生活感、色調 = 暖橘食慾色、燈光 = 窗邊自然光、主要餐點 = 法式吐司搭配草莓與蜂蜜、擺盤 = 家常溫暖擺盤、背景 = 木桌＋白色餐巾＋咖啡杯、道具 = 一本翻開的雜誌與小花瓶、比例 = 1:1、文字需求 = 不需文字
>
> **輸出咒語**（簡要）：
>
> 你是一位專業美食攝影師與 AI 繪圖師，擅長拍攝讓人食指大動的食物照。為早午餐咖啡廳生成一張 Instagram 貼文圖片。
>
> 風格溫暖生活感，暖橘食慾色調，窗邊自然光從左側灑入。淺景深凸顯主角法式吐司——金黃色澤、草莓鮮紅、蜂蜜緩緩流下。擺盤為家常溫暖風格，白色餐盤搭配木桌。背景有翻開的雜誌、小花瓶與冒著熱氣的咖啡杯，傳遞悠閒週末氛圍。比例 1:1 正方形，不需文字。

**✦ 注意事項**

- 食物照片的關鍵在「光澤」與「熱氣」——提示詞要強調
- 避免 AI 生成「看起來像塑膠」的食物（要加入「真實感」、「自然紋理」等關鍵字）
- 餐廳內景照要保留「人味」（稍微凌亂的桌面比完美擺設更吸引人）
- 若是咖啡廳，記得加上咖啡香氣的視覺化（蒸氣、拉花細節）

**✦ 預期產出範例**

> **輸入**：餐飲類型 = 日式拉麵店、長度 = 60 秒、主題 = 用餐體驗、鉤子 = 熱騰騰豚骨湯頭的特寫、氛圍 = 店面暖簾＋吧台座位＋師傅煮麵、食物展示 = 經典豚骨拉麵／叉燒飯／煎餃、價格 = 拉麵 180 元起、CTA = 地址＋營業時間、旁白 = 無旁白僅字幕、音樂 = 治癒 Lo-fi、音效 = 喝湯聲與煮麵水滾聲
>
> **輸出腳本**（簡要）：
>
> 0-3 秒：大特寫——乳白色豚骨湯在沸騰，蒸氣往上冒。字幕：「這一碗，值得排 30 分鐘。」
>
> 3-10 秒：店門口暖簾隨風飄動→切店內吧台座位→師傅專注煮麵。字幕：「藏在巷弄裡的日本味。」
>
> 10-40 秒：① 經典豚骨拉麵（10-20 秒）：叉燒肉在湯中擺動、半熟蛋切開流出蛋黃。字幕：「豚骨湯頭熬 12 小時。」② 叉燒飯（20-30 秒）：炙燒叉燒上的美乃滋用噴槍加熱。字幕：「叉燒飯是隱藏菜單。」③ 煎餃（30-40 秒）：底部金黃酥脆的煎餃，筷子夾起時的聲音。字幕：「來這裡的人都會再加一份煎餃。」
>
> 40-50 秒：菜單特寫，重點標示「拉麵 180 元」，字幕：「平價米其林等級。」
>
> 50-60 秒：店門口＋營業時間。字幕：「OOO 拉麵 · 台北市 OO 路 O 號 · 11:00-22:00」

**✦ 注意事項**

- 食物影片的前 3 秒決定觀看率——鉤子必須是「動態食物特寫＋誘人音效」
- 建議使用「ASMR 風格」——強調聲音（煎、炸、倒飲料、攪拌）
- 價格資訊要清楚顯示，不要用太小字

- 零售影片前 3 秒一定要展示商品「最強的賣點」——不要慢慢鋪陳
- 功能型商品（收納、防水、輕量）要用「視覺證明」——讓觀眾看到就信
- 服飾影片要使用真實人體模特兒，不要只用衣架展示
- 價格資訊要清晰顯示（放大字級、對比色背景）
