## 📖 ChatGPT 是什麼？

ChatGPT 是一個 **AI 對話機器人**，由一間叫 OpenAI 的公司開發。

我們用最簡單的方式來理解它：

### 把它想像成一個「超強圖書館員」

想像你走進一個超大圖書館，裡面有全世界所有的書。圖書館員（ChatGPT）讀過所有的書，而且記性超好。

- 你問它問題 → 它從讀過的書裡面找答案給你
- 你請它幫忙 → 它用讀過的書來幫你想辦法
- 你跟它聊天 → 它像一個讀了很多書的朋友跟你聊天

### 它的三大特色

**1. 🗣️ 用自然語言溝通**
你不用學程式、不用背指令，只要像平常講話一樣打字就行了。說中文、台語、英文都可以。

**2. 💾 記得住對話**
它會記得你在這一輪對話中說過什麼。你可以一直問，它會根據前後文繼續回答。

**3. 🔄 越問越精準**
一開始問得籠統沒關係，繼續追問就好。比如：
- 你：「推薦台北好玩的地方」
- 它：給一份清單
- 你：「裡面哪個適合老人家？」
- 它：幫你篩選出來

### ChatGPT 能做到的事

✅ **它很擅長：**

| 類別 | 範例 |
|------|------|
| 寫作 | 寫信、寫稿、寫賀卡、改作文 |
| 翻譯 | 中翻英、英翻中、日文、韓文 |
| 整理 | 把雜亂的資訊整理成表格或清單 |
| 說明 | 用簡單的話解釋複雜的概念 |
| 創意 | 想點子、寫故事、設計活動 |
| 規劃 | 安排行程、擬訂菜單 |

### ChatGPT 做不到的事（要小心！）

❌ **它不擅長或不能做的事：**

| 類別 | 說明 |
|------|------|
| 代替醫生 | 不提供醫療診斷，生病請看醫生 |
| 代替律師 | 不提供法律建議，重要法律問題請諮詢專業 |
| 保證 100% 正確 | 它可能會出錯，重要資訊記得自己再確認 |
| 記住你上次的對話 | 每次新開對話它會「忘記」之前的內容 |
| 知道你的個人資料 | 除非你告訴它，不然它不知道你是誰 |

> 💡 **使用 ChatGPT 的小心法：把它當成一個「很會聊天的朋友」，而不是「永遠正確的神」。它給的答案可以參考，但重要的決定還是要靠你自己判斷。**

## 使用 ChatGPT 的 3 個黃金原則

### 原則一：問得清楚，答得漂亮

**❌ 模糊的問法：**
> 「幫我寫東西」

**✅ 清楚的問法：**

```copy
請幫我寫一封生日祝賀信，給我 65 歲的媽媽，語氣要溫馨、不要太肉麻，長度大約 100 字。
```

### 原則二：不滿意就繼續問

第一次回答不滿意？沒關係，繼續追問：
- 「可以再簡短一點嗎？」
- 「換個輕鬆一點的語氣」
- 「幫我改成台語版本」

AI 不會不耐煩，你問幾次都可以。

### 原則三：重要的資訊要自己再確認

如果 ChatGPT 給你日期、數字、法律條文或醫療資訊，**最好再用 Google 查一下**，確保正確。
