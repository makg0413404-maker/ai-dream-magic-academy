## 📖 什麼是魔法咒語？

魔法咒語就是你**輸入給 AI 的文字指令**。

你打的每一個字，就像在對 AI 下達魔法指令：
- 你問：「今天天氣如何？」→ 這是咒語
- 你說：「幫我寫一封生日賀卡」→ 這也是咒語
- 你寫：「用簡單的話解釋什麼是通貨膨脹」→ 這還是咒語

**咒語越清楚，AI 越知道你要什麼。**

## 三種最實用的魔法咒語公式

我們幫你整理了三種最常用的咒語公式。你不需要全部記住，選一個你覺得最順手的就好。

### 公式一：角色＋任務＋格式

這是最萬用的咒語公式，適用於 90% 的情況。

**寫法：**
```
你是一個【角色】，請幫我【任務】。請用【格式】呈現。
```

**實際範例：**

```copy
你是一個專業的食譜作家，請幫我設計三天的家常菜菜單，適合兩位老人家食用。請用表格呈現，包含早餐、午餐、晚餐。
```

**實際範例：**

```copy
你是一個親切的旅遊顧問，請幫我規劃台北三日遊的行程，要適合銀髮族、不用走太多路。請用每日行程表的方式列出。
```

---

### 公式二：三步驟咒語

如果你的需求比較複雜，可以用這個公式，一步一步說清楚。

**寫法：**
```
1. 背景：【告訴 AI 情況】
2. 需求：【告訴 AI 你要什麼】
3. 限制：【告訴 AI 要注意什麼】
```

**實際範例：**

```copy
1. 背景：我要參加老同學聚餐，想跟大家分享最近在學 AI
2. 需求：請幫我準備一段 3 分鐘的介紹，用輕鬆有趣的方式
3. 限制：不要用太難的術語，大家聽得懂最重要
```

---

### 公式三：給範例咒語

當你想要 AI 按照某種風格回答時，先給它一個範例。

**寫法：**
```
請參考這個範例的風格來回答：

【範例內容】

現在請幫我做一個類似的：【你的需求】
```

**實際範例：**

```copy
請參考這個範例的風格：

「親愛的老友，好久不見，最近天氣變涼了，要記得加件外套喔！」

現在請幫我用同樣溫馨的語氣，寫一段關心正在住院的朋友的訊息。
```

## 🎯 如何把你的咒語變得更厲害？

### 1️⃣ 加細節

**普通咒語：**
> 幫我寫一封信

**厲害咒語：**

```copy
幫我寫一封感謝信給我社區的鄰居張太太，感謝她上週幫我收包裹。語氣要誠懇溫暖，大約 100 字以內。
```

### 2️⃣ 加語氣

```copy
請用輕鬆、像朋友聊天的方式，介紹 ChatGPT 給完全沒用過的長輩聽。
```

### 3️⃣ 加「如果……就……」

```copy
幫我整理一份銀髮族健康飲食建議。如果我有高血壓，請特別標註要注意的事項。
```

### 4️⃣ 不滿意就修改

- 「請再簡短一點」
- 「請換一個更像長輩的口吻」
- 「請用台語寫一次」
- 「請把重點用粗體標出來」

## 💡 魔法咒語小抄（貼在手機備忘錄！）

| 你想做什麼 | 咒語開頭這樣寫 |
|-----------|---------------|
| ✅ 比較 | 「請比較 A 和 B 的不同，用表格列出」 |
| ✅ 整理 | 「請幫我把以下重點整理成三點」 |
| ✅ 教學 | 「請用國小五年級聽得懂的話解釋○○」 |
| ✅ 翻譯 | 「請把以下內容翻成台語，口語一點」 |
| ✅ 潤稿 | 「請幫我調整這段文字的語氣，讓它更溫暖」 |
| ✅ 表格 | 「請用表格呈現以下資訊」 |
