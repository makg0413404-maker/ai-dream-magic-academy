# 📚 各行各業魔法咒語庫

> 「不用想破頭，我們幫你準備好了——直接複製，馬上使用。」

這裡有 **5 大行業**的實用魔法咒語，你可以在 ChatGPT 或任何 AI 工具中直接使用。

**使用方法：**
1. 找到你的行業
2. 選一個你想做的事
3. 複製咒語（長按 → 選取 → 複製）
4. 貼到 ChatGPT → 送出
