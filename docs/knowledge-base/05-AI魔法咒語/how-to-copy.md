# 一鍵複製教學｜輕鬆複製魔法咒語

> 看到喜歡的魔法咒語，一鍵就能複製到你的 AI 工具中使用。

---

## 一鍵複製功能說明

每個魔法咒語頁面下方都有一個「**一鍵複製**」按鈕：

```
┌─────────────────────────────┐
│ [📋 一鍵複製咒語]            │
│ 點擊即可複製整段提示詞       │
└─────────────────────────────┘
```

### 如何使用

1. 找到你想要的魔法咒語
2. 點擊「一鍵複製咒語」按鈕
3. 打開 ChatGPT 或 Gemini
4. 直接貼上（長按輸入框 → 貼上）

### 手機操作小提示

- **iPhone**：長按空白處 → 點選「貼上」
- **Android**：長按輸入框 → 點選「貼上」
