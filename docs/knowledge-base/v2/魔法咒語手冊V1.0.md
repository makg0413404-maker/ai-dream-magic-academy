## 如何複製咒語

### 📱 手機操作

**iPhone 複製步驟：**

1. 找到你要的魔法咒語區塊
2. 長按咒語文字，直到出現選取框
3. 拖動選取範圍，選取整段咒語
4. 點選「拷貝」（或「複製」）

**Android 複製步驟：**

1. 找到你要的魔法咒語區塊
2. 長按咒語文字，直到出現選取框
3. 拖動選取範圍，選取整段咒語
4. 點選「複製」

### 💻 電腦操作

1. 用滑鼠選取整段咒語文字
2. 按右鍵 → 點「複製」
3. 或按快捷鍵：`Ctrl + C`（Windows）／`Command + C`（Mac）

---

## 如何貼上到 AI 工具

### 📱 手機貼上步驟

1. 打開 ChatGPT App 或 即夢 App
2. 在對話輸入框 **長按**，直到出現選項
3. 點選 **「貼上」**
4. 如果需要上傳照片，點選輸入框旁的「📎」圖示，選取照片
5. 按 **送出**（➤ 或 ↵ 按鈕）

### 💻 電腦貼上步驟

1. 打開 ChatGPT 網站 或 即夢網站
2. 在輸入框按 **右鍵** → **「貼上」**
3. 或按快捷鍵：`Ctrl + V`（Windows）／`Command + V`（Mac）
4. 如果需要上傳照片，點選輸入框旁的「📎」或「+」圖示，選取照片
5. 按 **Enter** 送出

![一鍵複製示意圖](../../ai-dream-magic-academy-temp/public/images/textbook-illustrations/ch05-one-click-copy.png)

### 💡 小提醒

- **iPhone**：長按空白處 → 點選「貼上」
- **Android**：長按輸入框 → 點選「貼上」
- **電腦**：`Ctrl + V`（或 `Command + V`）最快
