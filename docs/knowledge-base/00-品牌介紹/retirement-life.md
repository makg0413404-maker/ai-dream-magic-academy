# 🌸 退休生活魔法咒語

> 退休不是終點，而是**第二人生的起點**！AI 工具可以幫你把生活變得更輕鬆、更有趣。無論是寫信給老朋友、規劃旅遊、還是學新東西，AI 都能當你的好幫手。

---

## 📝 日常實用

### 寫問候信給老朋友

```copy
請幫我寫一段問候訊息，給一位很久没見的老朋友。我想告訴他我很想念以前一起喝茶聊天的日子，並邀約下週有空見面。語氣要像老朋友講話一樣自然、溫暖，大約 80 字。
```

### 幫孫子說故事

```copy
你是一個很會說故事的阿公／阿嬤，請幫我編一個 3 分鐘的短故事給 5 歲的小朋友聽。故事的主題是「一隻小貓咪學會分享玩具」。要有可愛的角色、簡單的情節，最後有一個溫暖的結局。語氣要生動活潑。
```

### 家族聚會邀請

```copy
請幫我寫一則家族聚餐的邀請訊息，要在 LINE 群組發送。聚餐時間是這個週日中午 12 點，地點在台北市的「阿嬤的私房菜」餐廳。請用溫馨、開心的語氣，讓大家都想來參加。
```

## 💰 理財與生活

### 記帳提醒

```copy
請幫我寫一則每月記帳提醒，風格要輕鬆、不嚴肅。內容包含：提醒檢視這個月的開銷、有沒有不必要的花費、下個月可以怎麼調整。語氣像朋友提醒一樣，大約 70 字。
```

### 旅遊行程規劃

```copy
你是一個貼心的旅遊規劃師，請幫我規劃一個 3 天 2 夜的宜蘭慢活之旅。對象是 65 歲以上的夫妻，需求如下：
- 不要太趕的行程
- 景點之間距離不要太遠
- 有適合長者的步道或景觀餐廳
- 住宿要舒適、最好有電梯
請用每日行程表呈現，包含交通建議。
```

## 🧘 健康與興趣

### 運動菜單

```copy
你是一個專注於樂齡健康的健身教練，請幫我設計一份居家運動菜單，適合 65 歲以上長者每天做：
- 不需要任何器材
- 每個動作都有替代方案（如果膝蓋不好可以怎麼做）
- 總時間控制在 20 分鐘以內
- 注重平衡感和柔軟度
請用簡單的步驟說明。
```

### 養生食譜

```copy
你是一個擅長家常菜且懂養生的料理老師，請幫我設計一週的養生菜單，適合 60 歲以上的長者。原則：
- 少油少鹽但好吃
- 食材容易取得（傳統市場就買得到）
- 烹飪步驟不要太複雜
- 每餐有蔬菜和蛋白質
請用表格呈現：星期／早餐／午餐／晚餐。
```

## 🎯 興趣發展

### 學新東西的動機信

```copy
請幫我寫一段話，鼓勵一位 70 歲的朋友開始學畫畫。他總說「我年紀大了學不會」，請用溫暖、有力量的話告訴他：學習永遠不嫌晚，畫畫沒有對錯，重要的是過程中的快樂。大約 100 字。
```

### 社群分享

```copy
我最近學會用 AI 幫忙規劃旅遊，覺得很方便。請幫我寫一段心得分享，打算發在 LINE 群組或 Facebook 上。內容包含：
- 我本來覺得 AI 很難
- 沒想到這麼簡單
- 實際用 AI 規劃了一次旅遊
- 鼓勵朋友也試試看
語氣要像在跟老朋友聊天一樣自然。
```
