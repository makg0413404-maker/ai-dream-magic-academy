## CTA 按鈕設計規範

### 視覺規格

| 項目 | 建議值 | 說明 |
|:-----|:-------|:------|
| **底色** | 紫金色漸層（#7C3AED → #F59E0B） | 魔法學院品牌色，紫金代表魔法與高貴 |
| **字體顏色** | 白色（#FFFFFF） | 對比明顯、易讀 |
| **字體大小** | 28–32px | 大字，長輩友善 |
| **字重** | Bold（粗體） | 清楚易讀 |
| **內距** | 上下 20px、左右 40px | 大按鈕，容易點擊 |
| **圓角** | 12–16px | 溫和圓潤不死板 |
| **懸浮效果** | 放大 1.05 倍 + 發光陰影 | 增加互動感 |
| **點擊效果** | 微縮 0.95 倍 | 回饋感 |
| **圖示** | ✦ 四角星（在文字左側） | 品牌元素 |

## 手機版 vs 電腦版注意事項

### 手機版（學員常用）

| 項目 | 建議 |
|:-----|:------|
| CTA 按鈕大小 | 至少 48px 高（容易點擊） |
| 按鈕寬度 | 螢幕寬度 85%（不要滿版） |
| 三欄權益 | 改為直式三行（手機螢幕窄） |
| QR Code | 建議 250×250 px |
| 字體大小 | 至少 18px（長輩友善） |

### 電腦版（講師投影）

| 項目 | 建議 |
|:-----|:------|
| CTA 按鈕大小 | 更大、更醒目 |
| 三欄權益 | 橫式三欄 |
| QR Code | 建議 300×300 px（投影清楚） |
