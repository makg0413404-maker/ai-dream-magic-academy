> **文件狀態：** 規劃草案（標準咒語內容由 CEO 提供）
> **更新日期：** 2026-07-30
> **負責單位：** WorkBuddy

## 設計原則

1. **不教學員自己寫咒語：** 所有咒語皆為 CEO 提供的標準咒語，學員只需複製貼上
2. **生活咒語以熟齡有感需求為主：** 圍繞退休生活、家庭關係、個人興趣、社群互動
3. **商業咒語展示應用價值：** 讓學員知道 AI 不只是娛樂，還有實際商業用途
4. **每咒語統一格式：** 展示 → 複製 → 貼上 → 生成

### 講座操作建議

- **需要上傳照片的咒語：** 講座中由講師使用預先準備好的照片示範，學員回家用自己的照片練習
- **不需要上傳照片的咒語：** 講座中可讓學員現場跟著操作（只需複製貼上即可生成）
- 建議講座中優先示範不需要上傳照片的咒語（如節慶賀卡、社群封面照），降低學員操作門檻

## 咒語撰寫規範（供 CEO 參考）

每咒語建議包含以下元素：

```
[角色設定] + [指定場景] + [風格要求] + [輸出規格]
```

### 生活咒語範例結構

```
你是一位專業的[角色]，請幫我[做什麼]。風格：[風格描述]。
額外要求：[細節調整]。輸出格式：[圖片/比例]。
```

### 商業咒語範例結構

```
你是一位專業的[設計師/攝影師]，請為[商品/活動]設計[什麼]。
商品/活動描述：[描述]。目標感覺：[風格]。
輸出格式：[海報/貼文/商品圖]，圖片比例：[16:9/1:1/4:3]。
```

> **注意：** 以上僅為結構建議。實際標準咒語以 CEO 提供的最終版本為準。
