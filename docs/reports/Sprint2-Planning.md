## 六、技術風險

| 風險 | 影響 | 因應 |
|:-----|:-----|:------|
| spell-library 為 .md 文件，非 JSON | 無法直接掛接 clipboard JS | Codex 需將 .md 咒語內容讀入 JS 或建立 API |
| 14 咒語 × 8 情境 × 5 行業 = 多重分類 | 前台分類邏輯可能複雜 | 情境索引已建立，Codex 依此做標籤過濾 |
| 會員教材權限 | 會員才能看付費課程教材 | 沿用現有 Supabase Auth middleware |
