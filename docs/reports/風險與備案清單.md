## 🔴 高風險重點備案（詳細說明）

### 風險 1：現場網路斷線（機率：中｜影響：高）

**發生情境：** 場地 Wi-Fi 不穩、中華電信骨幹異常、太多裝置同時上網導致壅塞

**備案方案：**

| 層級 | 方案 | 說明 |
|:-----|:-----|:------|
| 🥇 第一線 | 切換手機熱點 | 講師手機開啟 4G/5G 熱點 → 筆電連線 → 可繼續操作 |
| 🥈 第二線 | 展示本機離線素材 | 所有 Demo 的截圖與錄影已下載到講師手機和筆電 |
| 🥉 第三線 | 無網路教學 | 發紙本講義 + 用白板手繪說明 AI 概念 |

**講座前檢查：**
- [ ] 確認場地 Wi-Fi 穩定（提前 30 分鐘到場測試）
- [ ] 講師手機熱點功能確認可用
- [ ] 備用截圖/影片已全部下載到本機（非雲端）
- [ ] 紙本講義已印製 20 份

---

### 風險 2：ChatGPT / 即夢服務異常（機率：低｜影響：高）

**發生情境：** OpenAI 伺服器忙碌、即夢維護中、被大量同時請求塞爆

**備案方案：**

| 服務異常 | 替代工具 | 說明 |
|:---------|:---------|:------|
| ChatGPT 無法連線 | Google Gemini App | 另一個免費 AI，功能類似 |
| ChatGPT Plus 生圖異常 | 即夢 App 生圖功能（免費） | 手機上操作 |
| 即夢分身功能異常 | 豆包 App | 台灣可下載的替代 App |
| 所有線上工具異常 | 展示預先截圖輪播 | 每個 Demo 備有 5–8 張截圖 |
| 完全無法生圖 | 用 ChatGPT 純文字版 | 展示咒語的「文字輸出」效果 |

**講座前檢查：**
- [ ] 所有備案截圖已依主題分類存放（形象照/合照/DM/分身/咒語）
- [ ] 備用工具 App（Gemini、豆包）已安裝並登入
- [ ] 備用工具帳號已事先創建

---

### 風險 5：Vercel 網站掛掉（機率：低｜影響：高）

**發生情境：** Vercel 部署異常、DNS 解析失敗、網站需要重新部署

**備案方案：**

| 層級 | 方案 | 說明 |
|:-----|:-----|:------|
| 🥇 第一線 | 重新整理頁面 | 有時候只是暫時性錯誤，F5 可解決 |
| 🥈 第二線 | 啟動本機 dev server | 在講座筆電上執行 `npm run dev` → localhost:3000 |
| 🥉 第三線 | 離線展示 | 展示截圖 + 直接操作 ChatGPT（不使用網站 UI） |

**講座前檢查：**
- [ ] 講座前 1 天部署最新版到 Vercel
- [ ] 講座當天提早 30 分鐘確認網站可正常開啟
- [ ] 本機 dev server 已安裝依賴並可快速啟動
- [ ] 離線版咒語庫 PDF 已存好（手機 + 筆電 + 紙本各 1 份）

## 🟡 中風險應對細節

### 風險 3：學員手機無法安裝 App（機率：高｜影響：中）

**可能原因：**
- 手機儲存空間不足
- 手機作業系統版本過舊（iPhone 需 iOS 16+ / Android 需 8+）
- 學員忘記 Apple ID 或 Google 帳號密碼
- 學員使用的是「智障型手機」（非智慧型手機）

**應對方式：**
1. **助教協助檢查：** 問「手機是哪一款？」「空間還夠嗎？」「有沒有 Apple ID？」
2. **無法安裝的學員：**
   - 提供電腦版操作流程（若有帶筆電的學員）
   - 由助教用備用平板代為操作
   - 直接使用手機瀏覽器版（chatgpt.com，不需安裝 App）
3. **講座後續追蹤：** 提供清除手機空間的教學文章，讓學員回家再試

### 風險 4：學員跟不上進度（機率：高｜影響：中）

**可能原因：**
- 這是學員第一次接觸 AI，資訊量太大
- 講師講太快（不自覺）
- 學員視力/聽力需要多一點時間
- 學員在某一環節卡住後，後面的都聽不懂了

**應對方式：**
1. **講座中：** 助教巡場主動關心進度較慢的學員，提供一對一協助
2. **每單元結束：** 問「大家都還好嗎？需要再等一下嗎？」
3. **講座後：** 
   - 提供講座全程錄影連結
   - 提供今天所有操作的電子書（PDF）
   - 邀請加入 Line 群組，課後可持續發問
4. **特別注意：** 不要把學員跟不上視為學員的問題——而是調整講解節奏的訊號

### 風險 6：手機版破版/跑版（機率：中｜影響：中）

**可能原因：**
- CSS 在不同手機瀏覽器上渲染不一致
- 字體大小在某些手機上過大或過小
- 按鈕位置跑掉

**應對方式：**
1. **講座前 1 天：** 用 3 種常見手機型號（iPhone 15 / Samsung S24 / 中階 Android）測試所有頁面
2. **講座當天：** 提早 30 分鐘用手機實際操作一遍主要流程
3. **若現場發現破版：** 切到本機 dev server（已修復版本），或改用縮放瀏覽器
4. **講座後：** 紀錄破版情況，納入下一版修復項目

### 風險 7：提示詞工具（Magic Spell Engine）異常（機率：中｜影響：高）

**可能原因：**
- Magic Spell Engine 本身的 Bug
- 咒語召喚 API 回傳錯誤
- 表單無法送出

**應對方式：**
1. **重新整理頁面：** 很多時候可以解決
2. **切到離線版：**
   - 打開預先下載的咒語庫 PDF（手機裡）
   - 學員直接複製 PDF 中的咒語文字
   - 貼到任意 AI 工具使用
3. **改用 ChatGPT 直接教學：**
   - 使用「三步驟咒語公式」現場示範
   - 教會學員「角色＋任務＋格式」這一個萬用公式
4. **發紙本咒語庫：** 印製 20 份紙本咒語庫，學員可帶回家

## 🟢 低風險應對

### 風險 8–10：設備相關

1. **投影設備故障：** 備用 HDMI 線已準備；也可直接用 15 吋筆電螢幕搭配小組輪流觀看
2. **麥克風問題：** 確認場地大小（若小於 20 人，不用麥克風即可）
3. **學員手機沒電：** 準備 1 個排插 + 3 條充電線（Lightning + Type-C + Micro USB）

### 風險 13–14：學員相關

1. **人數過多：** 增加助教人力（每 5 位學員配 1 位助教）
2. **特殊需求學員：** 報名表加「特殊需求」欄位，事先掌握

### 風險 15：緊急狀況

- 講座前由場務組確認逃生路線與集合點
- 講座開始時口頭告知逃生出口位置
